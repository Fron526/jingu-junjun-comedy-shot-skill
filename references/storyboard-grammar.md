## 1. 喜剧镜头单位

金桔俊俊式分镜的最小单位不是一句台词，而是一次理解变化。金桔说出的前半句可能只是铺垫；正常角色的第一眼神可以充当无声回复；切回金桔落下后半句才完成包袱；正常角色随后需要足够时间把字面、规则和自身损失联系起来。

优先使用以下结构：

```text
金桔铺垫半身 → 正常角色预反应 → 金桔落包袱 → 正常角色3秒长反应 → 金桔等待 → 正常角色纠正台词
```

若包袱依赖道具：

```text
金桔半身起句 → 道具／手部特写 → 回金桔落包袱 → 正常角色3秒长反应 → 金桔等待 → 正常角色台词
```

## 2. V级基础画面

每个V先写两套完整画面，不能直接进入S。

```markdown
**V级金桔半身反打基础画面：**
①背景：……
②环境：机位在……，朝……，使用@环境参考；光从……
③人物：金桔清晰；正常角色以……作前景锚点
④构图：金桔在……三分线；道具在……；视线余量在……
⑤镜头参数：9:16，65mm，胸上中近景，眼平，水平，浅景深，固定

**V级正常角色半身主视角基础画面：**
①背景：……
②环境：机位在……，朝……，使用@环境参考；光从……
③人物：正常角色清晰；金桔以……作前景锚点
④构图：正常角色在……三分线；柜面和道具在……
⑤镜头参数：9:16，65mm，胸上中近景，眼平，水平，浅景深，固定
```

V级说明只负责空间与摄影。人物在当前S如何动、看、呼吸和停顿，必须在S中重新写。

## 3. 三秒反应

关键包袱后的正常角色反应不得短于3秒。推荐逐秒写：

- **0—1秒，听清：** 原动作刹停，眼睛锁住金桔，营业表情开始消失。
- **1—2秒，复算：** 视线移到活动牌、手机、房间、自己的手或脚下，把歪理与现实成本连接起来。
- **2—3秒，压住：** 重新看金桔，下颌绷紧或略松又闭紧，鼻腔吸气，肩颈变硬，手抬起又压住，为下一句纠正蓄力。

反应应随包袱变化：第一次是怀疑听错；中段是复算成本；后段是压火和放弃语言。不要九次都用同一套瞪眼模板。

三秒反应还必须服从全片的累计失控曲线：前段反应结束后仍能平稳解释；中段反应结束后，下一句应更短、更硬并带明显重音；后段反应结束后，可以突然拔高、抢话、语速加快，或因气到说不出话而改用动作。反应镜与接下来的台词镜是一段连续表演，呼吸、手势和情绪强度不能在切镜处归零。

## 4. 五官超近景与高度连续性

当眼神、眉眼、鼻息、嘴角或下颌变化承担核心信息时，使用独立的100—105mm五官怼脸超近景。超近景只演闭口反应；人物要说话时，下一S切回同侧65—85mm近景。

超近景和回切近景必须共同写清四类锚点：

1. **空间锚点：** 继续使用同一环境参考。即使景深很浅，也要写出脸后仍可辨认的焦外背景，例如暖墙色块、深木竖框、货架水平线或固定灯斑；禁止纯色棚拍背景、凭空出现的新墙面或左右翻转。
2. **站位锚点：** 人物双脚站位、身体与柜台的前后距离不变。裁掉胸肩不等于人物靠近、升高或坐下。
3. **高度锚点：** 摄影机光轴维持人物眼平，水平俯仰0度；近侧眼中心固定在画面高度约38%，头部中心和头顶方向不漂移。切到超近景时沿原光轴改变焦段或水平推进，禁止升降摄影机、俯拍、仰拍或为了填满画面重新垂直居中。
4. **切回锚点：** 回切近景第一帧恢复前一近景的头顶留白、肩线和柜台高度，同时保留超近景结束时的视线、眼睑、嘴角、呼吸和下颌状态。若动作需要腰上景，人物眼睛仍保持同一纵向高度，只向下扩展画幅。

推荐在每套正常角色基础画面的镜头参数中给出一次本V硬参数，并在相关S重复最容易漂移的内容：

```text
同一站位与同一眼平光轴；近侧眼中心固定在画面高度38%。超近景保留脸后焦外的暖墙、深木竖框与货架横线，背景方位不换。回切近景只向下恢复肩胸和柜台，不改变头部纵向位置。
```

如果生成工具不能可靠理解“沿光轴推进”，应把近景首帧或基础画面作为超近景的构图参考，并明确“从同一帧裁切放大”；不能只提供人物角色图，否则环境和高度会重新抽样。

## 5. 道具插镜

活动牌、手机数字和手势只在它们改变理解时插入。通常0.5—1.5秒。文字必须完整、正向、无遮挡；手机数字稳定；手指路径清楚。插镜不能成为孤立产品图，应保留柜面、袖口、对方虚化上身或环境锚点。

## 6. 跨V剪辑

先列V边界表，逐项写开始主体和结束主体。推荐：

```text
Vn结束：正常角色纠正台词
Vn+1开始：金桔捕捉上句关键词并形成新歪理
```

这样跨V仍是正反打。若边界两侧都是正常角色，合并反应与台词、提前结束上一V或延后下一V起点，直到主体交替。

## 7. 时间分配

在90秒密集台词喜剧中，时长优先级为：台词可听清 > 核心3秒反应 > 证据可读 > 金桔等待 > 装饰性动作。需要腾时间时，先删重复点头、重复指物、重复解释和无信息空镜。

可复制提示词中的字幕控制只写“无字幕”。“字幕后期加”“后期再做字幕”等内容是给制作人员的工作说明，不能混入交给生成模型的提示词。
